step1: 首选是医生独立评分：
双击打开软件: 医生独立评分
黑窗口出现，里面有个网址http://localhost:5001，在服务器里打开这个网址
每一个评完之后点'下一个'操作，可以对一个患者评分,自动记录评分和用时
一次性肯定是评不完的，就可以直接关闭窗口。下次再按照上述方式打开，已评分的与未评分在浏览器的患者列表种的是有区别的，一眼就看出来了，不用担心
当然也可能临时一两分钟 三五分钟..有事，回头再评分的时候，那个页面上计时的还在走着，这时候你重新点击一下这个患者，时间又从0开始计时了。
点错了要重新评分也是，重新点击一下这个患者，评分就又是新的了。
